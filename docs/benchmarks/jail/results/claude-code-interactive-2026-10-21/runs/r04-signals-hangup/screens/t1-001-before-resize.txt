● A History of Version Control Systems: From SCCS to Git

  The Problem Before Version Control

  In the earliest days of computing, source code lived on punched cards, paper tape, and magnetic reels. "Versioning"
  meant physically labeled decks and carefully maintained filing cabinets. As programs grew and teams expanded, the
  informal habits that replaced this (copying files to foo.c.old, foo.c.bak2, foo_final_REALLY.c) could not keep pace.
  Programmers needed answers to basic questions: who changed this line, when, why, and how do we get back to the version
  that worked last Tuesday? Version control systems (VCS) grew out of the need to answer those questions mechanically.
